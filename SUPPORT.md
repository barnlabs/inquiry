# Support

Inquiry is an early developer preview maintained by BarnLabs.

- Ask usage and installation questions in GitHub Discussions when available.
- Report reproducible bugs with the Inquiry version or commit, operating system, exact command, expected behavior, actual behavior, and a synthetic or public test case.
- Do not attach private notes, PHI, credentials, confidential investigations, copyrighted course files, or unredacted reports.
- Use GitHub's private security-advisory flow for vulnerabilities; follow [SECURITY.md](SECURITY.md).
- For brand or organizational questions, email `hello@barnlabs.net` without including secrets or sensitive research material.

BarnLabs does not provide emergency, medical, legal, financial, or investigative-response support through this project.
