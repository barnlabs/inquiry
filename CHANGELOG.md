# Changelog

All notable changes will be documented here. Inquiry follows semantic versioning after its first tagged release.

## 0.1.0 — developer preview

- Rust research CLI and provenance-preserving report schema.
- Native macOS SwiftUI research and InquiryStudy workspaces.
- Stdio MCP server with deterministic math, conversion, statistics, calculus, graph, place, medication-label evidence, research, report, study, and timeline tools.
- World Bank, Wikidata, Wikipedia, MedlinePlus, OpenAlex, Open Library, NASA 3D, Wikimedia Commons, and optional SearXNG paths.
- Exact current/numbered officeholder resolution with ambiguity abstention.
- U.S. current-president official corroboration and identity-bound licensed portrait provenance.
- Self-contained reports and timelines; Anki, Quizlet, Markdown, JSON, and CSV-oriented exports.
- Local course-material indexing with bounded parsers, citations, change-detection hashes, and risk-gated recall export.
- Project-scoped Codex and Grok Build MCP configuration plus a documented Ollama-through-Codex path; ChatGPT remains explicitly unshipped pending a secure supported remote MCP path.
- Inquiry brand system, downloadable assets, checksums, and BarnLabs product/blog pages.

Known risks and experimental areas remain documented in [SECURITY.md](SECURITY.md) and [ROADMAP.md](ROADMAP.md).
