# Inquiry macOS resources

`Inquiry.png` is the BarnLabs Inquiry product mark used by the local macOS app bundle. The public repository's canonical vector, downloadable variants, checksums, and usage rules live in [`brand/`](../../../brand/); the BarnLabs site mirrors that same kit.

Brand intent: a magnifying lens containing a connected evidence trail. Forest, evidence teal, and source gold match the public Inquiry identity. Do not use the mark to imply that BarnLabs verified or endorsed a third-party source or conclusion.
